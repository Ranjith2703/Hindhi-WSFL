# 🎓 Hindian Spoken Hindi Academy Website

> A modern and interactive educational website designed for a Hindi learning academy, featuring premium UI design, smooth animations, course showcases, testimonials, and responsive user experience.

🔗 **Live Demo:** [HINDIANACADEMY](https://hindianacademy.vercel.app/)

---

## ✨ Features

* 🎬 Animated preloader with branding
* 📊 Scroll progress indicator
* ✨ Interactive particle background
* 🎯 GSAP-powered hero animations
* 📈 Animated statistics counters
* 📱 Fully responsive design
* 🍔 Mobile navigation menu
* 🎓 Course showcase section
* 📚 Learning syllabus timeline
* ⭐ Testimonials slider
* 🖼️ Gallery carousel
* 🎠 Swiper.js integration
* 🎭 Scroll reveal animations (AOS)
* 🃏 3D card tilt effects
* 🎨 Glassmorphism UI design
* 🌟 Floating visual effects
* 📞 Call & WhatsApp quick actions
* 🗺️ Google Maps integration
* ❓ FAQ accordion section
* ⚡ Smooth scrolling navigation
* 👀 Visitor counter integration

## 🚀 Getting Started

No build tools required.

```bash
# Clone repository
git clone https://github.com/your-username/hindian-spoken-hindi-academy.git

# Open project
cd hindian-spoken-hindi-academy

# Run
open index.html
```

Or simply open `index.html` in your browser.
